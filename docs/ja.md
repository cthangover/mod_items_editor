# Items Editor — フォームで MOD のアイテムを編集する

Items Editor は、ゲームの実行中に MOD のアイテムを編集します: MOD の各言語での名前と説明、価格、画像、アイテムの種類、インベントリから使うときのアクション。**保存**は MOD のファイルを書き込み、ゲームは変更をすぐに表示します——再起動も再読み込みも不要です。

ツールボックス（ツールバーのハンマー）から**アイテム**として開きます。

## フォーム

- **Id** — アイテムの id。シナリオ、ショップ、マップ、他の MOD がこれでアイテムを見つけます。
- **名前**と**説明** — 翻訳キーと、MOD の言語ごとの行。新しいアイテムには id から作ったキーが付き、テキストは MOD のローカライズファイルに入ります。
- **価格** — コイン単位（ショップは独自の価格を設定できます）。
- **アイコン** — アイテムグループの画像。**…** で選ぶためのグリッドが開きます。
- **種類** — Quest、Used、TargetUsed、Food、Resource、Recipe、CantDrop。複数付けられます。
- **アクション** — アイテムを使うと何が起こるか: `null` か、読み込まれた MOD が登録するアイテムアクションの一つ（`action/heal`、`action/equip`…）。
- **他の MOD のフィールド** — 他の MOD がスキーマでアイテムに付けるフィールド（たとえば Equipment の装備タイプ、特性、装備できるクラス）は、同じ種類のエディターとともに専用セクションに現れます。
- **その他のフィールド** — アイテムの JSON の残り全部。JSON のまま表示・編集され、そのまま保たれます。

ツールバー: **新規**（Ctrl+N）は `<mod>/new_item`——アクションなし、価値 1 コインのリソース——を追加します。**コピー**（Ctrl+D）、**削除**、**元に戻す**/**やり直す**（Ctrl+Z / Ctrl+Y）。保存はテキストが変わったファイルだけを書き込み、新しいアイテムは `items/<mod>.json` に入ります。

## どのアイテムを編集できるか

一覧に現れるのは一つの MOD のアイテム——その MOD 自身のファイルにあるものです。MOD の一覧には、フォルダーとしてインストールされた MOD だけが並びます。その MOD を編集せずに別 MOD のアイテムを変えるには、自分の MOD で同じ id を配り、所有者への依存関係を宣言します。Items Editor 自体は選んだ MOD のファイルだけを編集します。

## うまくいかないとき

1. **MOD の一覧が空。** 書き込める MOD がありません。パッケージ済みの MOD は編集できません。
2. **インベントリに古い名前が出る。** アイテムがゲームの言語とは別の言語で保存されました。ゲームの言語の行を確認してください。
3. **アクションの一覧にアクションがない。** それを登録する MOD がこのゲームに読み込まれていません。
